# Utopia Province Sim

A React + TypeScript + Vite app for loading Utopia intel exports and comparing a live province against a saved baseline snapshot.

## Current features

- Load province data from Intel Site CSV export
- Switch between CSV-driven and manual province setup
- Compare baseline vs current values
- Edit core province fields inline
- View economy, military, buildings, science, and networth sections
- Age 114 race and personality data
- Building efficiency, income, wages, food, population, and core military calculations

## Current status

This is still an alpha build. Some calculations are implemented, while several sections still contain placeholders or simplified logic.
